# Certificate Images

Place your certificate images in this folder with the following names:

- `dicoding-backend-js.jpg` - Back-End Development with JavaScript certificate
- `dicoding-web-intermediate.jpg` - Web Development Intermediate certificate  
- `dicoding-frontend-fundamentals.jpg` - Front-End Web Development Fundamentals certificate
- `dicoding-git-github.jpg` - Git & GitHub Fundamentals certificate
- `huawei-hcia-ai.jpg` - HCIA–AI V4.0 Certification
- `vsga-data-scientist.jpg` - Associate Data Scientist Training certificate

Recommended image specifications:
- Format: JPG or PNG
- Size: 800x600px or similar aspect ratio
- Quality: High resolution for clear viewing
